# windots

A Windows terminal that behaves like a good Unix one, without pretending to be one.
PowerShell 7 + Windows Terminal, Catppuccin Mocha end to end, one idempotent installer.

```
❯ gs
## main...origin/main
 M config/starship.toml
```

| Layer | Choice |
|---|---|
| Shell | PowerShell 7 (`pwsh`) |
| Terminal | Windows Terminal — Catppuccin Mocha, opacity 92, no acrylic |
| Font | CaskaydiaCove NFM (Nerd Font Mono) 11 pt, ligatures + `calt` |
| Prompt | starship, custom powerline on the Catppuccin Mocha palette |
| Line editor | PSReadLine — ListView prediction, `HistoryAndPlugin`, Catppuccin token colours |
| Fuzzy | fzf + PSFzf — `Ctrl+R` history, `Ctrl+T` files, `Alt+C` cd |
| Navigation | zoxide, aliased over `cd` |
| Coreutils | eza (`l ll la lt ltt`), bat (`view` / `less`), fd, ripgrep (`grep`) |
| Git | delta pager, side-by-side, `zdiff3`, `pull.rebase`, `fetch.prune` |
| Icons | Terminal-Icons |
| Elevation | gsudo, aliased to `sudo` |

Everything is Catppuccin Mocha: terminal scheme, starship palette, PSReadLine syntax
colours, fzf colours, bat theme, delta syntax theme. One palette, no seams.

Exact versions of everything installed: **[docs/VERSIONS.md](docs/VERSIONS.md)** (regenerated by `sync.ps1`).
Full keymap: **[docs/CHEATSHEET.md](docs/CHEATSHEET.md)** (also `cheat` in the shell).

## Install

```powershell
git clone https://github.com/TheoM83/windots.git
cd windots
.\install.ps1
```

That is the whole thing. No admin, no reboot. Then open a new Windows Terminal tab.

Set your git identity at the same time if the machine is fresh:

```powershell
.\install.ps1 -GitUserName 'Jane Doe' -GitUserEmail 'jane@example.com'
```

Want to see what it would touch first:

```powershell
.\install.ps1 -WhatIf
```

Flags: `-SkipPackages`, `-SkipModules`, `-SkipFont`, `-SkipTerminal`.

### What the installer actually does

1. **Preflight** — Windows, winget, and a sane repo checkout.
2. **Packages** — winget, one pass, exact ids. Already-installed packages are detected
   through `winget export` (the `winget list` table truncates long ids) and skipped.
3. **Relaunch** — if you started it from Windows PowerShell 5.1, it re-executes itself
   under `pwsh` as soon as pwsh exists, so modules and `$PROFILE` land in the right place.
4. **Modules** — Terminal-Icons, CompletionPredictor, PSFzf, `CurrentUser` scope,
   via PSResourceGet when available. **PSReadLine is not installed**: 2.4.x ships inside
   PowerShell 7.6, and a gallery copy would only shadow it with something older.
5. **Font** — CaskaydiaCove Nerd Font Mono, downloaded from the Nerd Fonts release and
   registered under `HKCU`. Per-user, so no elevation.
6. **Config** — see the table below.
7. **Verify** — prints the version of every tool it expects, whether the font registered,
   and whether bat can resolve the Catppuccin theme. Failures are summarised at the end
   and set a non-zero exit code.

It is safe to re-run. Files whose content already matches are reported and left alone.

### Where the files go

| Repo file | Lands at | How |
|---|---|---|
| `config/Microsoft.PowerShell_profile.ps1` | `$PROFILE.CurrentUserCurrentHost` | copy |
| `config/starship.toml` | `~\.config\starship.toml` | copy |
| `config/bat/config` | `%APPDATA%\bat\config` | copy |
| `config/bat/themes/Catppuccin Mocha.tmTheme` | `%APPDATA%\bat\themes\` | copy, then `bat cache --build` |
| `config/gitconfig` | `~\.config\git\windots.gitconfig` | copy + `include.path` in `~\.gitconfig` |
| `config/windows-terminal-settings.json` | Windows Terminal `LocalState\settings.json` | **merge** |

Two of those deserve an explanation.

**git is included, not overwritten.** The tracked fragment carries no `[user]` section.
It is dropped next to your config and referenced with a single `include.path` line, so your
identity, credential helper and any work-specific overrides in `~\.gitconfig` survive
untouched — and `git config --global` keeps behaving the way you expect.

**Windows Terminal is merged, not replaced.** Profile GUIDs are generated per machine.
Copying a foreign `settings.json` over yours points `defaultProfile` at a profile that does
not exist locally, and Windows Terminal silently falls back to Windows PowerShell 5.1.
The installer instead merges: it applies `profiles.defaults`, the colour schemes, the
keybindings and the window settings, leaves `profiles.list` alone, and re-points
`defaultProfile` at *your* PowerShell Core GUID. The tracked
`config/windows-terminal-settings.json` has `profiles.list` and `defaultProfile` stripped
out entirely, so the repo contains exactly what the merge applies and nothing it ignores.

Before the first overwrite of any file, the original is copied once to
`<name>.windots-backup` and never touched again.

## Keeping it in sync

Edit the real files, use the shell, then record the result:

```powershell
.\sync.ps1        # live config -> repo, plus a regenerated docs/VERSIONS.md
git diff
```

`sync.ps1` never commits. It also refuses to read `~\.gitconfig` — it only ever pulls the
fragment back, so an identity can't leak into a commit.

On another machine, the round trip is `git pull` then `.\install.ps1`.

## Local overrides

The profile dot-sources `profile.local.ps1` from `Documents\PowerShell\` as its very last
step, if the file exists. Machine-specific aliases, proxies and paths go there: it is not
tracked, and it wins over everything above it.

## Gotchas

- **The font must be the Mono variant.** Windows Terminal has to say `CaskaydiaCove NFM`,
  not `CaskaydiaCove NF`. The propo variant misaligns every powerline separator.
- **`bat cache --build` is mandatory** after dropping in the tmTheme. Without it
  `--theme="Catppuccin Mocha"` errors and delta quietly loses its syntax colours.
- **`ls` and `cat` stay native on purpose.** They return objects, so
  `ls | Where-Object Length -gt 1MB` keeps working. eza and bat live under their own
  names (`l`, `ll`, `view`, `less`) because they emit text, which is for reading, not piping.
- **F1 / F2 need PSReadLine ≥ 2.4** (`ShowCommandHelp`, `SwitchPredictionView`). That comes
  with PowerShell 7.6; on an older pwsh the installer warns instead of silently degrading.
- **7-Zip is not in the package list.** `extract` handles `.7z` only if `7z` is on PATH.
  `winget install 7zip.7zip` if you want it.
- **Windows Terminal must have run once** before the installer can merge its settings —
  the `LocalState` folder does not exist until then. The installer says so and carries on.
- **`gh-completion.ps1`** is generated on first shell start and cached next to the profile;
  it is regenerated only when `gh.exe` is newer than the cache. It is not tracked here.

## Layout

```
windots/
├── install.ps1                 machine <- repo
├── sync.ps1                    machine -> repo
├── config/
│   ├── Microsoft.PowerShell_profile.ps1
│   ├── starship.toml
│   ├── gitconfig               included fragment, no identity
│   ├── windows-terminal-settings.json
│   └── bat/
│       ├── config
│       └── themes/Catppuccin Mocha.tmTheme
└── docs/
    ├── CHEATSHEET.md           every key and alias
    └── VERSIONS.md             generated by sync.ps1
```

## Profile load time

The profile stamps its own cost into `$env:PROFILE_LOAD_MS`. If it creeps up, the usual
suspects are a cold `gh-completion.ps1` cache and module auto-loading.

```powershell
❯ $env:PROFILE_LOAD_MS
```
